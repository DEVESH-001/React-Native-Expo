## EAS [https://docs.expo.dev/eas/]

`Expo Application Services, a suit of cloud/hosted services that handle building, releasing, updating & automoating Expo & React Native apps.`

### The Four Main Components

1. EAS Build
   build the app binaries in the cloud
2. EAS Submit
   updates the app to the app stores
3. EAS Update
   pushing OTA (Over-The-Air) updates to the app
4. EAS Workflow
   automate the build and submit process(CI/CD)

### Development Build

is a custom version of your app that includes:

- Debug information
- Additional logging
- Hot reload support
- Debug builds with debugging tools

For Play-Store : AAb -> Google Prefers
For App-Store : IPA(ios app archive)
